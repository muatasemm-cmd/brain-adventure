# رحلة العباقرة — Brain Adventure

لعبة تعليمية عربية للأطفال مبنية باستخدام Flutter، تعمل دون اتصال بالإنترنت وتقدّم التعلم داخل مغامرة ومراحل ومكافآت.

## النسخة الحالية

- ملفات لاعبين محلية مستقلة، قابلة للإضافة والتعديل والحذف.
- أربع مغامرات مستقلة: الرياضيات والعلوم والمعرفة والمنطق.
- كل مادة تحتوي 20 مرحلة، وفي كل مرحلة 5 أسئلة: 80 مرحلة و400 سؤال إجمالًا.
- خرائط وخلفيات مصورة محلية مضمّنة في التطبيق وتعمل دون إنترنت.
- إنشاء ملف شخصي بالاسم والعمر والصورة دون أي لاعبين افتراضيين.
- تتغير صياغة الأسئلة والأرقام والمحتوى حسب الفئات العمرية 5–7 و8–10 و11–14.
- 6 أنماط تحديات: اختيار، صح/خطأ، إدخال رقم، ترتيب، مطابقة، وذاكرة.
- حفظ تلقائي واستئناف من أول تحدٍ غير مكتمل لكل طفل.
- صعوبة متكيّفة حسب العمر وإتقان كل مجال، مع دعم وتلميحات مبكرة عند الحاجة.
- تلميحات متدرجة وشرح تعليمي بعد الإجابة.
- نجوم وعملات وبلورات ومتجر وغرفة شخصية وإنجازات.
- منطقة ولي أمر محمية برمز PIN وتقارير لكل طفل.
- إعدادات محلية للمؤثرات والموسيقى والراوي والاهتزاز.
- Android مختبر فعليًا على المحاكي، ومشروع iOS موجود وجاهز للبناء على macOS.

## التشغيل والتحقق

```powershell
D:\develop\flutter\bin\flutter.bat pub get
D:\develop\flutter\bin\flutter.bat analyze
D:\develop\flutter\bin\flutter.bat test
D:\develop\flutter\bin\flutter.bat run -d emulator-5554 --no-dds
```

بناء Android:

```powershell
D:\develop\flutter\bin\flutter.bat build apk --debug
```

بناء iOS يجب أن يتم على macOS مع Xcode:

```bash
flutter build ios
```

## البنية

```text
lib/
  main.dart
  app.dart
  data/       # محتوى العالم وكتالوج المكافآت
  games/      # ألعاب الترتيب والمطابقة والذاكرة
  models/     # اللاعب والتقدم والتحديات والمكافآت والإعدادات
  screens/    # الترحيب واللاعبون والعالم والغرفة وولي الأمر والإعدادات
  services/   # الحفظ والتكيّف والمكافآت والإعدادات
  widgets/    # مكوّنات الواجهة المشتركة
test/         # اختبارات التخزين والعالم والألعاب والتكيّف والواجهة
```

كل بيانات الأطفال والتقدم محفوظة محليًا بواسطة `SharedPreferences` ولا يحتاج مسار اللعب إلى شبكة.

## ملاحظات الإصدار

- يلزم اختيار معرّف حزمة نهائي بدل `com.example.brain_adventure` قبل نشر المتاجر.
- مفاتيح توقيع Android وشهادات iOS وبيانات المتجر ليست جزءًا من المستودع، وتُجهّز عند النشر.
- الموسيقى والراوي لهما إعدادات محفوظة، لكن إضافة حزم صوتية مرخّصة تبقى خطوة محتوى منفصلة.
